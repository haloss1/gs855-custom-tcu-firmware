## GS8.55 Alpina-style port v2.0.0-beta: UNTESTED

> **Not flashed or driven by anyone yet.** Checksums and file structure are verified, but the
> behaviour is not. Prefer v1.0.0 unless you want to test, ideally on a spare unit. If you try it,
> please report back (shift quality, lockup judder, fault memory).

**Only for:** GS8.55, Bosch 0 260 002 502, BMW 1423159 / HW 2A, ZIF B22 P0_24 / 42C0 / RD43,
assembly ZB 1423169 / SW 1423170.

### Changes (on top of v1.0.0)
- **Alpina torque-converter lockup** (0x94F0): engages earlier, closes fully at engage, two extra
  lockup groups, stays locked under high pedal. Expect a more direct feel, possibly more low-rpm
  vibration.
- **About 950 bytes of further Alpina calibration** in 0xC000-0xFFFF: 182 runs whose BMW stock bytes
  and context occur exactly once in the GS8.55, plus 38 curves with identical axes. Most of these
  tables' functions are not identified.
- Not included: the pressure-like tables at 0xD000 (different axes and scale on the GS8.55).

Full list: [docs/changes-v2.md](../changes-v2.md) (1,328 bytes vs stock). Method:
[docs/04](../04-alpina-analysis-and-porting.md).

### Go back to v1 immediately if you notice
Judder on light throttle, slipping or flaring shifts, harsh engagement into D/R, or any TCU fault.
