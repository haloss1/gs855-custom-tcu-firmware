## GS8.55 Alpina-style port v1.0.0

Flashed with WinKFP, verified by full read-back and driven on one E39 M62 pre-TU.

**Only for:** GS8.55, Bosch 0 260 002 502, BMW 1423159 / HW 2A, ZIF B22 P0_24 / 42C0 / RD43,
assembly ZB 1423169 / SW 1423170. Check before flashing.

### Changes
- S gate goes straight to manual mode (no S mode, no tip needed first)
- Manual mode holds gears until you shift
- Adaptive driving-style switching off
- Alpina shift points: later full-load upshifts (about 48/85/126/195 vs 43/77/115/184 raw)

Not included: Alpina converter lockup and pressure changes (see v2.0.0-beta).

Full list: [docs/changes-v1.md](../changes-v1.md) (253 bytes).
